# OpenClaw

**OpenClaw** is an open-source, self-hosted AI agent gateway that provides a unified interface for AI assistants across multiple messaging platforms. Connect your favorite LLM to WhatsApp, Telegram, Discord, Slack, and more—all from a single, privacy-respecting deployment.

![OpenClaw System Architecture](/openclaw/diagrams/system-architecture.svg)

The architecture above shows how OpenClaw connects external messaging platforms through a central gateway to LLM providers, with persistent storage for configuration and sessions.

## At a Glance

| Aspect | Description |
|--------|-------------|
| **Architecture** | Gateway-centric, WebSocket-based control plane |
| **Deployment** | Docker containerized or native Node.js |
| **AI Integration** | 15+ LLM providers supported |
| **Extensibility** | Plugin-based channel connectors and skills |
| **State Management** | File-based JSON configuration with hot-reload |
| **License** | MIT (Open Source) |

## Quick Start

Get OpenClaw running in minutes with Docker:

```bash
# Clone the repository
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# Run automated setup
bash ./docker-setup.sh
```
