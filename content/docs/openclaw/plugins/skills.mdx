# OpenClaw Skills

Skills are modular capabilities that extend your AI assistant's functionality. Each skill provides specialized tools for specific tasks, from weather queries to code execution.

## Skill Architecture Overview

<img src="/diagrams/skills/skill-architecture.svg" alt="Skill Architecture" style={{width: '100%', maxWidth: '900px', margin: '20px 0'}} />

Skills work as a routing layer between user requests and specialized capabilities. When a user sends a message, OpenClaw's gateway routes the request to the appropriate skill based on the context.

## Skill Status Legend

| Status | Badge | Meaning |
|--------|-------|---------|
| **Eligible** | 🟢 | Ready to use, all requirements met |
| **Blocked** | 🔴 | Missing binary or configuration |
| **Disabled** | ⚫ | Manually disabled in config |

## Eligible Skills (Ready to Use)

These skills work immediately without additional setup.

### Weather

Get current weather conditions and forecasts for any location worldwide without requiring an API key.

<img src="/diagrams/skills/weather-skill.svg" alt="Weather Skill" style={{width: '100%', maxWidth: '700px', margin: '20px 0'}} />

**Usage Examples:**
```
@openclaw What's the weather in New York?
@openclaw Give me a 5-day forecast for Tokyo
@openclaw Will it rain tomorrow in London?
```

### Healthcheck

Perform security audits on your OpenClaw deployment, checking firewall, SSH, ports, and services.

**Usage Examples:**
```
@openclaw run a security healthcheck
@openclaw check my system security
@openclaw audit SSH settings
```

### Skill-Creator

Create custom skills with proper structure, manifest files, and packaging.

**Usage Examples:**
```
@openclaw create a new skill called "my-custom-skill"
@openclaw help me design a skill for tracking expenses
```

### Coding Agent

<img src="/diagrams/skills/coding-agent-skill.svg" alt="Coding Agent Skill" style={{width: '100%', maxWidth: '800px', margin: '20px 0'}} />

AI-Powered code writing, execution, and debugging assistant. One of the most powerful skills in OpenClaw.

**Capabilities:**
- ✓ Multi-language support (Python, JS, Go, Rust, etc.)
- ✓ File system read/write operations
- ✓ Git operations (commit, push, branch, etc.)
- ✓ Package management (npm, pip, cargo)
- ✓ Test execution and debugging
- ✓ Code explanation and refactoring

**Usage Examples:**
```
@openclaw write a Python script to sort a list
@openclaw fix the bug in main.js line 42
@openclaw refactor this function to use async/await
@openclaw create a React component for user login
@openclaw run npm install and then npm test
```

## Productivity Skills

<img src="/diagrams/skills/productivity-skills.svg" alt="Productivity Skills" style={{width: '100%', maxWidth: '800px', margin: '20px 0'}} />

### Notion

Manage Notion pages, databases, and content.

**Installation:**
1. Go to [notion.so/my-integrations](https://notion.so/my-integrations)
2. Create integration, copy token
3. Share pages with integration
4. Add `NOTION_API_KEY` to Skills page or `.env`

**Usage Examples:**
```
@openclaw create a Notion page titled "Weekly Report"
@openclaw search my Notion for "marketing plan"
@openclaw add "Review PR" to my Tasks database
```

### Trello

Manage Trello boards, lists, and cards.

**Installation:**
```bash
# Install jq
choco install jq  # Windows
brew install jq   # macOS

# Get credentials from trello.com/app-key
# Add to .env:
TRELLO_API_KEY=your_key
TRELLO_TOKEN=your_token
```

### Obsidian

Work with Obsidian vaults and markdown notes.

**Installation:**
```bash
brew install obsidian-cli
```

### GitHub

<img src="/diagrams/skills/github-skill.svg" alt="GitHub Skill" style={{width: '100%', maxWidth: '700px', margin: '20px 0'}} />

Interact with GitHub repositories, issues, PRs, and CI.

**Installation:**
```bash
# Windows
choco install gh

# macOS
brew install gh

# Linux
curl -fsSL https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo dd of=/usr/share/keyrings/githubcli-archive-keyring.gpg
sudo apt install gh

# Authenticate
gh auth login
```

**Usage Examples:**
```
@openclaw list open issues in owner/repo
@openclaw create issue "Bug: Login fails" in my-org/my-repo
@openclaw show PR #123 in owner/repo
@openclaw merge PR #456
@openclaw what CI runs failed today?
```

## Communication Skills

<img src="/diagrams/skills/communication-skills.svg" alt="Communication Skills" style={{width: '100%', maxWidth: '800px', margin: '20px 0'}} />

### Slack

<img src="/diagrams/skills/slack-skill.svg" alt="Slack Skill" style={{width: '100%', maxWidth: '700px', margin: '20px 0'}} />

Control Slack - react, pin/unpin messages.

**Installation:**
1. Create Slack App at api.slack.com/apps
2. Add bot scopes: chat:write, reactions:write, pins:write
3. Enable Socket Mode, generate App Token
4. Install to workspace, copy Bot Token
5. Add tokens to openclaw.json channels.slack

**Usage Examples:**
```
pin the message above
react to that with 🎉
unpin the announcement in #general
```

### Voice-Call

Start voice calls via OpenClaw voice-call plugin.

**Enable:**
```json

  "plugins": {

      "voice-call": {
        "enabled": true
      }
    }
  }
}
```

## Enabling/Disabling Skills

### Via Control UI

1. Go to `http://localhost:18789/skills`
2. Find the skill
3. Click "Enable" or "Disable"
4. Add API key if required

### Via Config

```json
{
  "skills": {
    "entries": {
      "skill-name": {
        "enabled": true
      }
    }
  }
}
```
