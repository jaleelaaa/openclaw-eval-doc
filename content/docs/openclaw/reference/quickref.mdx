# Quick Reference Card

Fast reference for common OpenClaw commands and configurations.

## Docker Commands

| Command | Description |
|---------|-------------|
| `docker compose up openclaw-gateway` | Start gateway |
| `docker compose up -d openclaw-gateway` | Start in background |
| `docker compose down` | Stop all services |
| `docker compose restart openclaw-gateway` | Restart gateway |
| `docker logs openclaw-openclaw-gateway-1 --tail 50` | View logs |
| `docker logs -f openclaw-openclaw-gateway-1` | Follow logs |
| `docker exec -it openclaw-openclaw-gateway-1 /bin/sh` | Enter container shell |


## Common Fixes

### Control UI "pairing required"

Add to `openclaw.json`:
```json
{
  "gateway": {
    "controlUi": {
      "allowInsecureAuth": true,
      "dangerouslyDisableDeviceAuth": true
    }
  }
}
```

### Discord Bot Not Responding to DMs

Add to `openclaw.json`:
```json
{
  "channels": {
    "discord": {
      "dm": {
        "enabled": true,
        "policy": "open",
        "allowFrom": ["*"]
      }
    }
  }
}
```

## Minimal Working Configuration

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "google/gemini-3-flash-preview"
      }
    }
  },
  "channels": {
    "discord": {
      "enabled": true,
      "token": "YOUR_DISCORD_BOT_TOKEN",
      "groupPolicy": "open",
      "dm": {
        "enabled": true,
        "policy": "open",
        "allowFrom": ["*"]
      }
    }
  },
  "gateway": {
    "port": 18789,
    "mode": "local",
    "bind": "loopback",
    "auth": {
      "mode": "token",
      "token": "YOUR_GATEWAY_TOKEN"
    },
    "controlUi": {
      "allowInsecureAuth": true,
      "dangerouslyDisableDeviceAuth": true
    }
  },
  "plugins": {
    "entries": {
      "discord": {
        "enabled": true
      }
    }
  }
}
```

## DM Policy Options

| Policy | Behavior |
|--------|----------|
| `"pairing"` | New users get a pairing code, owner must approve (default) |
| `"open"` | Anyone can DM (requires `allowFrom: ["*"]`) |
| `"allowlist"` | Only users in `allowFrom` list |
| `"disabled"` | No DMs allowed |

## Valid Auth Modes

<Callout title="Important" type="warn">
  Only `"token"` or `"password"` are valid auth modes. There is no `"none"` option.
</Callout>

```json
{
  "gateway": {
    "auth": {
      "mode": "token",
      "token": "your-secure-token"
    }
  }
}
```

## Troubleshooting Checklist

- [ ] Docker Desktop is running
- [ ] Gateway container is running: `docker ps`
- [ ] No config errors in logs: `docker logs openclaw-openclaw-gateway-1 --tail 10`
- [ ] Token included in URL for Control UI
- [ ] Discord bot token is valid
- [ ] DM policy set to "open" with allowFrom: ["*"]
- [ ] Gateway restarted after config changes
- [ ] Message Content Intent enabled in Discord Developer Portal

## Key Learnings

1. **Docker networking quirk**: Browser connections through Docker appear as remote (172.18.0.1), triggering pairing requirements.

2. **Valid auth modes**: Only `"token"` or `"password"` - there is no way to disable auth completely.

3. **Config changes require restart**: Always run `docker compose restart openclaw-gateway` after editing openclaw.json.

4. **Discord requires both settings**: For open DMs, you need BOTH `policy: "open"` AND `allowFrom: ["*"]`.

5. **CLI limitations in Docker**: The CLI container can't always reach the gateway. Edit config files directly on the mounted volume instead.
